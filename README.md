# Zeiterfassung

Winzige Seite zum Starten, Stoppen und Nachtragen von Arbeitszeiten.
Schreibt direkt in eine Notion-Datenbank, ohne Server und ohne Build.

Es sind **keine Zugangsdaten enthalten**. Der Notion-Token wird beim ersten
Öffnen abgefragt und bleibt ausschließlich im localStorage des jeweiligen
Geräts. Ohne eigenen Token mit Zugriff auf die hinterlegte Datenbank tut die
Seite nichts.

Quelle im Arbeitsbereich: `projects/tuneflow/tools/zeiterfassung.html`
